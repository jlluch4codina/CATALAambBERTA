# Català amb la Berta 1 📚📱

**Català amb la Berta 1** és una aplicació web interactiva, accessible i adaptada per practicar la sintaxi i la gramàtica catalana de manera visual, amena i dinàmica.

---

## 🌟 Característiques principals

* **Disseny Accessible & High-Legibility**:
  * Tipografia adaptada amb espaiat de lletra i línia millorat per facilitar la lectura.
  * Botons i seleccions tàctils de mida XXL per evitar clics d'error en dispositius mòbils.
  * Interfície clara amb colors pastel de contrast elevat per reduir la fatiga visual.
  * Barra de navegació inferior fixa (*Bottom Nav*) per a un accés ràpid des de qualsevol pantalla.

* **Contingut Pedagògic i Exercicis Interactius**:
  1. **Pas 1 - Identificació del Verb**: Exercicis per localitzar el verb principal de l'oració.
  2. **El Sintagma Nominal (SN)**: Identificació de determinants, nuclis i complements del nom (adjectius, sintagmes preposicionals i oracions).
  3. **Apostrofació de l'Article Femení**: Pràctica de la regla de *"La"* davant de vocals *i/u* àtones i tòniques.
  4. **Subjecte i Frases Impersonals**: Classificació de subjectes expressats, el·líptics i oracions impersonals.

* **Banc de Dades Ampliat i Test Final**:
  * Generació aleatòria de preguntes a cada nova sessió o en clicar **"Nous Exercicis"**.
  * Qüestionari final aleatori de 5 preguntes amb avaluació i retroalimentació immediata.

---

## 🛠️ Tecnologies utilitzades

* **HTML5** (Estructura semàntica i accessible)
* **Tailwind CSS** (Disseny adaptatiu i estil visual)
* **JavaScript (ES6+)** (Generació dinàmica d'exercicis, gestió d'estats i validacions)
* **FontAwesome / Google Fonts** (Tipografies Lexend i Fredoka, iconografia visual)

## 🚀 Com executar el projecte localment

1. Clona aquest repositori o descarrega els fitxers:
   ```bash
   git clone https://github.com/el-teu-usuari/catala-amb-la-berta-1.git
   ```
2. Accedeix a la carpeta del projecte:
   ```bash
   cd catala-amb-la-berta-1
   ```
3. Obre el fitxer `index.html` directament a qualsevol navegador web.

---

## 🌐 Publicació a GitHub Pages

Per publicar l'aplicació gratuïtament a internet:

1. Puja els fitxers `index.html` i `README.md` a la branca principal (`main`) del teu repositori de GitHub.
2. Ves a la secció **Settings** del repositori a GitHub.
3. Al menú lateral esquerre, selecciona **Pages**.
4. A **Build and deployment > Branch**, tria `main` i la carpeta `/ (root)`.
5. Fes clic a **Save**. GitHub generara l'enllaç públic de la teva app en pocs minuts.
